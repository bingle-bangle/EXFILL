# EXFILL

Unreal Engine 5 기반의 3인칭 FPS 서바이벌 게임 팀 프로젝트입니다.

교육과정에서 진행한 4인 팀 프로젝트로, 팀원들과 역할을 분담하여 게임 시스템을 개발했습니다.
저는 **아이템 상호작용 시스템, 아이템 데이터 관리 시스템, 탈출 시스템**의 설계 및 구현을 담당했습니다.

## 담당 역할

- 탈출 시스템 설계 및 구현
- 클라이언트와 서버 간 시스템 동작 흐름 구현

## 주요 구현

### 1. Item Tracer

플레이어가 바라보는 방향을 기준으로 주변의 상호작용 가능한 아이템을 탐지하고,
적절한 아이템을 선택하는 시스템입니다.

#### 구현 내용

- 플레이어 전방에 반원 형태의 Overlap 영역 생성
- 감지된 오브젝트 중 아이템만 필터링
- 플레이어와 아이템 간의 거리 비교
- 플레이어의 시선 방향과 아이템 방향을 비교하여 적절한 대상 선택
- 벡터 내적을 활용하여 플레이어가 바라보는 방향에 가까운 아이템을 판별

#### 동작 흐름

```text
플레이어 위치 및 방향
        ↓
전방 Overlap 영역 생성
        ↓
주변 오브젝트 탐지
        ↓
아이템 필터링
        ↓
거리 및 방향 비교
        ↓
상호작용 대상 선택
```
---
### 2. Item Data Management
GameplayTag, DataTable, DataAsset을 활용하여 아이템 데이터를 역할에 따라 분리하고 관리하는 시스템입니다.

### 데이터 관리 구조
```text
GameplayTag
    ↓
아이템 식별 및 분류

DataTable
    ↓
아이템 공통 메타데이터 관리

DataAsset
    ↓
개별 아이템의 상세 속성 및 동작 관리
```

### 구현내용
- GameplayTag를 활용한 아이템 식별 및 분류
- DataTable을 활용한 아이템 메타데이터 관리
- DataAsset을 활용한 개별 아이템의 상세 데이터 관리
- 아이템 식별 정보와 상세 데이터를 분리하여 관리

아이템의 종류가 늘어나더라도 데이터를 효율적으로 관리할 수 있도록 각 데이터의 역할을 분리하는 데 중점을 두었습니다.

---
### 3. Escape System
플레이어의 탈출 아이템 사용부터 탈출 성공 및 시스템 종료까지의 전체 흐름을 구현했습니다.

특히 멀티플레이 환경을 고려하여 클라이언트와 서버의 역할을 분리하고,
탈출 조건 및 주요 게임 상태의 검증은 서버에서 처리하도록 구성했습니다.

### 동작 흐름
```text
플레이어 탈출 아이템 사용
        ↓
탈출 이벤트 시작
        ↓
서버에서 아이템 검증
        ↓
탈출 영역 생성
        ↓
플레이어 탈출 영역 진입
        ↓
탈출 조건 확인
        ↓
탈출 성공 처리
        ↓
탈출 플레이어 정보 기록
        ↓
탈출 영역 정리
```
### 주요구현
- 클라이언트에서 탈출 아이템 사용 및 이벤트 요청
- 서버에서 탈출 아이템 유효성 검증
- 아이템 종류에 따른 탈출 영역 생성
- 탈출 영역 진입 감지
- 서버에서 탈출 조건 검증
- 탈출 성공 처리 및 플레이어 정보 기록
- 탈출 영역 종료 및 시스템 초기화

클라이언트의 입력과 서버의 검증 및 게임 상태 변경을 분리하여 멀티플레이 환경에서 안정적으로 동작할 수 있도록 구현했습니다.

### 담당 시스템 구조
Player
  │
  ├── Item Tracer
  │       └── 주변 아이템 탐지 및 상호작용 대상 선택
  │
  ├── Item Data
  │       ├── GameplayTag
  │       ├── DataTable
  │       └── DataAsset
  │
  └── Escape System
          ├── 아이템 사용
          ├── 서버 검증
          ├── 탈출 영역 생성
          ├── 탈출 조건 확인
          └── 탈출 성공 처리

---
### 개발중점
팀 프로젝트에서 담당 시스템의 기능 구현뿐만 아니라 다른 시스템과의 연결 및 동작 흐름을 고려하며 개발했습니다.

특히 아이템과 플레이어의 상호작용을 자연스럽게 처리하기 위한 탐지 로직과,
GameplayTag, DataTable, DataAsset을 활용한 데이터 관리 구조를 설계했습니다.

또한 탈출 시스템에서는 클라이언트와 서버의 역할을 구분하고,
서버에서 주요 조건을 검증하도록 구성하여 멀티플레이 환경을 고려한 시스템 구현에 중점을 두었습니다.
